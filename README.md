# Real Estate Audit Tool 

I’ve been working on automating data workflows using Python, and I just finished a script for a Real Estate Audit.

The tool takes a list of properties, calculates the annual yield based on market value and rent, and automatically flags any opportunity hitting a 7% target as 'High Yield.' It’s a simple but effective way to turn a raw CSV file into an actionable audit in seconds.
